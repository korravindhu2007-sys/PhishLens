# PhishLens

## About the Project

PhishLens is a cybersecurity awareness project designed to help users understand and identify phishing threats.

## Features

- Phishing awareness
- Interactive cybersecurity interface
- Phishing-related educational information
- Simple and user-friendly design

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose

The project aims to improve cybersecurity awareness and help users recognize common phishing threats.

## Project Type

Cybersecurity / Web Development Project
